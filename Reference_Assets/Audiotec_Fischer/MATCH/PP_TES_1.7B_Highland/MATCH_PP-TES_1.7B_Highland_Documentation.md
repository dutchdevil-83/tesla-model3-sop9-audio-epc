# MATCH PP-TES 1.7B Highland

Official documentation: https://www.audiotec-fischer.de/en/match/adaptors-harnesses/pp-tes-1-7b-highland

Manufacturer facts checked 2026-09-10:
- Order number M141320.
- Intended for Tesla Model 3 Highland from MY 10/2023 and Model Y Juniper from MY 02/2025 with Ryzen and factory standard sound system.
- Official amplifier target is MATCH UP 10DSP.
- Power supply for the amplifier must be wired separately.
- Includes Tesla system connectors and a 5 m cable for a separate 2 x 2-ohm subwoofer.
- Cable harness length: 1 m.

Project caveat: using this harness as a Tesla-side interposer for Audison is a custom adaptation, not manufacturer-documented Audison plug-and-play compatibility.
