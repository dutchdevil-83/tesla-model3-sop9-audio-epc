## Current MB proposal
Hardware only: EUR 4,010.90 incl. VAT. Cabling, damping, mounting/consumable material and labour are excluded. Installation is DIY.

Architecture evidence:
- AF M8.14 bit: front stage.
- AF M4D: rear woofer/midrange zone, optional rear tweeters.
- AF M1D: donor Pioneer woofer amplifier candidate; electrical load must be measured/verified.
- X569/X579 upper/headliner immersive positions: omitted for music-first build based on two installer recommendations. Dashboard center is retained.
