Recommended reversible installation

Best wiring method: a professionally assembled, correctly keyed cabin-side interposer/breakout at the confirmed BAUDIO body-controller connector. It preserves every unrelated pin with a tested pass-through, disconnects the original audio-source pair from the door-side tweeter circuit, and routes only the downstream tweeter pair to HELIX H or I.

Factory condition

Reversible interposer

Not a generic splice. The X033B/X053A housing is shared with window, latch and/or sensor circuits. Do not use random T-taps, insulation-displacement connectors, solder on factory conductors, or an unverified whole-plug adapter. Never drive H/I into a pair still attached to the factory amplifier. If an appropriate non-destructive connector solution is unavailable, leave the factory harness untouched and use an automotive specialist to specify the matching service connector/terminal set.

Minimal new materials

Two individually identified twisted two-conductor speaker cable runs (choose suitable automotive-rated flexible insulation and conductor cross-section for the real route), correct mating OEM connector or repair-terminal system proven from the actual removed connector, protective sleeve, non-damaging harness fixings and a small documentation label on each end. Cable lengths must be measured from the actual installed HELIX position; no reliable length is established by the Tesla models.
