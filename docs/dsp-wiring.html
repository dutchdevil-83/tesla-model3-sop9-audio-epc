Provisional commissioning guidance
No AFPX file or live DSP changes made

Main to Virtual Routing

Enable VCP in DCM. Use ISA to measure individual Tesla inputs and their combined frequency responses before calculating the front L/R full-range virtual feeds. Virtual names below are DSP PC-Tool signal functions, not physical output letters.

Virtual to Output Routing and crossover starting points

HP = high-pass; LP = low-pass; LR24 = Linkwitz–Riley 24 dB/oct. The values below are starting estimates, never measured acoustic crossover settings. Protect all tweeters before enabling any output.

Subwoofer remote gotcha: VCP OFF ties SubRC to physical K/L. VCP ON assigns SubRC by virtual Subwoofer 1 (K) / Subwoofer 2 (L) to any routed physical outputs. For your planned J/K subwoofer channels, VCP MUST be on, and DIRECTOR must control both in a real test.

Equalizer, frequency response and level

Input EQ / ISA

Start EQ flat. Measure highlevel A/B/C/D/E/F/G individually using ISA, then measured A+C and B+E. Align overlap in amplitude and phase before calibrated summation; do not apply equal 100% to arbitrary overlapping bands.

If low/TW and dash are already full-range, select the appropriate sole source instead of summing. Do not try to recreate entirely absent frequencies with EQ boosts.

Virtual and output EQ

Start Virtual EQ and Output EQ at 0 dB. Keep all sound effects OFF during the baseline: RealCenter, Augmented Bass, loudness and rear attenuation until routing is proven. Apply HP/LP filters to speaker outputs, not just virtual groups.

Start channel gains at -12 dB, with H/I at -18 dB and muted until protected. Measure with RTA/microphone before finalizing EQ, phase, time alignment, or boosts.
